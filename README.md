# Akbar Movies

**AI-Powered Image & Meme Generator with Animation and Puzzle Features**

Akbar Movies is a fun and creative web application that lets users generate high-quality images and animated memes using AI. Create stunning visuals in multiple resolutions, turn them into short animated GIFs, and challenge yourself with interactive jigsaw puzzles.

---

## Features

### 1. Multi-Resolution Image Generation
- Support for a wide range of resolutions:
  - Standard (512×512, 768×768, 1024×1024)
  - Anime-style optimized resolutions
  - 3D-style high detail resolutions
  - Portrait / Landscape / Square formats
  - Custom pixel dimensions
- All generated images are created according to the selected resolution

### 2. Animated Meme Generator
- Create short animated memes (maximum **5 seconds**)
- Dynamic background changes during animation
- Smooth transitions and effects
- One-click download as **.GIF** file
- Perfect for social media sharing

### 3. Jigsaw Puzzle Mode
- Convert any generated image or meme into an interactive jigsaw puzzle
- Multiple difficulty levels (Easy / Medium / Hard)
- Drag-and-drop piece assembly
- Timer and move counter
- Replay any generated creation as a puzzle

### 4. User-Friendly Interface
- Clean and modern UI
- Real-time preview
- Easy resolution selector
- Prompt input for AI generation
- Instant download options (PNG / JPG / GIF)

---

## How It Works

1. Enter a text prompt describing the image or meme you want
2. Choose your preferred resolution (including 3D and Anime styles)
3. Generate the image
4. Optionally convert it into a 5-second animated meme with background effects
5. Download as GIF or turn it into a jigsaw puzzle

---

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- AI Image Generation: Integrated AI model
- Animation: Canvas / CSS animations for GIF creation
- Puzzle Engine: Custom JavaScript jigsaw system
